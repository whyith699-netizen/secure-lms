Yang akan kamu pelajari
Membuat program mengambil keputusan menggunakan if, else if, dan else.

Satu kondisi, dua kemungkinan.

Program tidak selalu berjalan lurus. Kadang kita perlu memilih apa yang terjadi berdasarkan sebuah kondisi. Di JavaScript, kita menggunakan if untuk memeriksa apakah kondisi tersebut benar.

// Apakah sudah waktunya belajar?
const waktu = "sore";

if (waktu === "sore") {
  console.log("Buka SECURE!");
} else {
  console.log("Sampai nanti.");
}

Coba sendiri

Buat variabel nilai. Tampilkan “Lulus” jika nilainya minimal 75, dan “Coba lagi” jika di bawah 75.
